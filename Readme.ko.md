# Morrowisp — macOS를 위한 차분한 뽀모도로 타이머

규칙적인 하루 리듬을 돕는 차분한 macOS 메뉴 막대 뽀모도로입니다. 집중하고, 쉬고, 하던 일로 돌아오는 흐름을 부드럽게 이어 줍니다.

앱 화면은 시스템 언어에 따라 영어와 한국어를 지원합니다. 한국어 외의 언어에서는 영어로 표시합니다. 만든 사람은 **SW Square**입니다.

## ✨ 주요 기능

- **뽀모도로 타이머**: 설정된 시간 동안 집중하고 쉴 수 있도록 도와주는 타이머 기능입니다.
- **설정 창**: 집중/휴식 시간과 긴 휴식 간격, 알림음(시스템 사운드 14종 + 끄기), 세션 자동/수동 전환, 로그인 시 자동 실행 등을 설정할 수 있습니다.
- **세션 자동/수동 전환**: 집중→휴식, 휴식→집중 전환을 자동으로 하거나, 직접 클릭해서 시작하도록 선택할 수 있습니다.
- **전환 관리**: 집중 전에 할 일과 보상을 적고, 집중이 끝나면 휴식을 시작할지 10분 더 할지 직접 고릅니다. 그때 적어 둔 다음 시작점은 다음 집중에서 다시 보여 줍니다.
- **복귀와 휴식 추천**: 휴식 중에 "복귀"를 누르면 휴식을 여기서 마치고, 적어 둔 할 일과 다음 시작점 그대로 바로 집중을 시작합니다. 휴식 화면에는 짧은 휴식 거리(물 한 잔, 스트레칭 등)를 한 줄 보여 줍니다. (전환 관리를 켰을 때)
- **하루의 미션과 보상 목록 (1.4)**: 오늘의 메인 미션 한 가지를 적고 끝냄을 표시합니다. 작은 · 중간 · 큰 보상은 설정에서 관리하고 팝오버에서 고릅니다. (전환 관리를 켰을 때)
- **오늘 요약과 주간 회고 (1.4)**: 오늘 마친 집중 수 · 실제 집중 분 · 연장 횟수와 주로 한 일을 보고, 기록 창에서 지난 7일의 미션과 집중 기록 · 이번 주에 도움이 된 것을 돌아봅니다. (전환 관리를 켰을 때)
- **지난 기록 다시 쓰기**: 할 일·보상 칸 옆 단추로 지난 집중에 적었던 글을 골라 넣고, 기록 창에서는 줄마다 그때 적은 글을 봅니다.
- **집중 로그**: 뽀모도로 세션이 완료될 때마다 자동으로 로그가 기록됩니다.
- **로그 통계**: 기록된 로그를 차트로 시각화하여 일별 집중 시간을 한눈에 파악할 수 있습니다.
- **메뉴바 연동**: 메뉴 바에서 남은 시간(또는 진행 바)과 긴 휴식까지의 사이클을 확인할 수 있습니다.
- **알림 기능**: 집중 또는 휴식 시간이 끝나면 사용자에게 알려줍니다.
- **Obsidian 연동**: 세션이 끝날 때마다 Obsidian 데일리 노트에 초 단위 기록과 하루 통계를 자동으로 남깁니다. ([가이드](docs/OBSIDIAN.ko.md))
- **단축어 연동**: 집중이 시작할 때와 끝날 때 단축어 앱의 단축어를 실행합니다(방해금지 켜고 끄기 등). ([가이드](docs/SHORTCUTS.ko.md))
- **업데이트**: 새 버전이 나오면 받아 두고 메뉴 막대 아이콘에 빨간 점으로 알립니다. 아이콘을 눌러 나오는 **업데이트**를 누르면 설치하고 다시 켭니다. 앱이 켜져 있는 동안 스스로 설치하지는 않으며, 누르지 않고 앱을 끄면 그때 설치됩니다. (설정 > 일반 > 업데이트)

할 일과 보상 메모, 집중 종료 시 선택, 복귀, 휴식 추천, 하루의 미션, 보상 목록, 오늘 요약, 주간 회고를 사용하려면 **설정 > 타이머**에서 **전환 관리**를 켜세요.

오늘 요약의 완료 횟수는 끝까지 마친 집중만 셉니다. 집중 분은 중간에 그만둔 세션도 실제 집중한 시간만큼 합친 뒤 분으로 내립니다. 자정을 걸친 세션은 끝난 날에 집계하며, 연장한 집중은 한 번으로 셉니다. 완료 표식이 없는 예전 기록은 시간에 포함하되 완료 여부는 추측하지 않습니다.

## 💻 사용 기술

- **SwiftUI**: Apple의 최신 UI 프레임워크를 사용하여 앱의 전체 인터페이스를 구축했습니다.
- **SwiftData**: 뽀모도로 세션 로그를 사용자의 기기에 안전하게 저장하고 관리합니다.
- **Combine**: 비동기 이벤트를 처리하고 데이터 흐름을 관리하기 위해 사용되었습니다.

## 🚀 시작하기

### 요구사항

- macOS 14.0 이상
- Xcode 16.0 이상 (소스에서 빌드할 때)

### 설치

1. [릴리스](https://github.com/JeongSeongWon1116/Morrowisp/releases/latest)에서 `Morrowisp-<버전>.zip`을 받아 풀고, `Morrowisp.app`을 응용 프로그램 폴더로 옮깁니다.
2. 처음 열 때 macOS가 "확인되지 않은 개발자"라며 막습니다(Apple 공증을 받지 않은 앱입니다). **시스템 설정 > 개인정보 보호 및 보안**에서 "그래도 열기"를 누르거나, 터미널에서 아래 한 줄을 실행한 뒤 다시 엽니다.
    ```bash
    xattr -dr com.apple.quarantine /Applications/Morrowisp.app
    ```
3. 그 뒤의 새 버전은 앱이 스스로 받아 두고 메뉴 막대 아이콘에 점으로 알립니다. **업데이트**를 누르면 설치됩니다(누르지 않고 앱을 끄면 그때 설치됩니다).

요구사항: macOS 14.0 이상.

### Pomodoro(옛 이름)에서 옮겨 오기

Morrowisp 2.0.0은 번들 식별자가 다른 새 앱입니다. `Morrowisp.app`을 직접 설치합니다. Pomodoro에서 자동 업데이트되지 않으며 기록과 설정은 이어지지 않습니다. 옛 `Pomodoro.app`은 종료한 뒤 지워도 됩니다. 앱을 지워도 옛 자료 폴더 `~/Library/Containers/Jeong.Pomodoro`는 남습니다.

### 소스에서 빌드

1.  이 저장소를 로컬 컴퓨터에 복제(clone)합니다.
    ```bash
    git clone https://github.com/JeongSeongWon1116/Morrowisp.git
    ```
2.  Xcode에서 `Morrowisp.xcodeproj` 파일을 열고 **Morrowisp** 스킴을 선택합니다.
3.  빌드하고 실행합니다 (Cmd+R). Xcode에서 실행한 개발 빌드는 자동 업데이트를 확인하지 않습니다. 릴리스를 만드는 법은 [docs/RELEASE.ko.md](docs/RELEASE.ko.md)에 있습니다.

저장소 폴더에서 공유 스킴으로 빌드·시험하려면:

```bash
xcodebuild -project Morrowisp.xcodeproj -scheme Morrowisp -configuration Release -destination 'platform=macOS' -derivedDataPath ~/Library/Developer/Morrowisp-build/dd build
xcodebuild -project Morrowisp.xcodeproj -scheme Morrowisp -destination 'platform=macOS' -derivedDataPath ~/Library/Developer/Morrowisp-build/dd test
```
